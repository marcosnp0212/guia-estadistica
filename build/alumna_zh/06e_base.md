# Parte 0. Repaso de base: números y calculadora

学统计之前，我们先复习要用到的几种运算。哪个你已经会了，就跳到下一个。

## 0.1. 运算顺序（El orden de las operaciones）

一个算式里有好几种运算时，不是简单地从左到右算。顺序是这样的：

1. 先算**括号里**的。
2. 然后是**乘方和开方**（“平方”、根号）。
3. 然后是**乘法和除法**。
4. 最后是**加法和减法**。

例子：2 + 3 × 4 = 2 + 12 = **14**（不是 20，因为先算乘法）。

例子：(2 + 3) × 4 = 5 × 4 = **20**（括号优先）。

::: {custom-style="Ojo"}
**⚠️ 注意。** Excel 也完全按这个顺序。写 `=2+3*4` 得到 14。如果想先加，必须加括号：`=(2+3)*4`。考试里很多错误来自忘了括号，尤其是做除法时：`=A1+A2/2` 和 `=(A1+A2)/2` 不一样。
:::

## 0.2. 小数和四舍五入（Decimales y redondeo）

在西班牙（和你的西班牙语版 Excel 里），小数用**逗号**写：0,477。老师的讲义里有时用点（0.477），因为是用英文软件做的。意思一样。这份指南里也用逗号。

四舍五入到 2 位小数，看第三位小数。如果是 0、1、2、3 或 4，第二位不变。如果是 5、6、7、8 或 9，第二位加一。

- 1,2521 → 第三位是 2 → 保持 **1,25**。
- 0,4772 → 第三位是 7 → 进位 → **0,48**。
- 2,3456 → 第三位是 5 → 进位 → **2,35**。

在 Excel 里：`=REDONDEAR(A1;2)`（英文版：ROUND）把 A1 的内容四舍五入到 2 位小数。也可以不改数字，用“开始”（Inicio）选项卡里的“增加/减少小数位数”按钮，它只改变显示。

::: {custom-style="Truco"}
**💡 小技巧。** 不要在题目做到一半时四舍五入。让 Excel 用全部小数计算，只把最后结果四舍五入。如果提前四舍五入，最后的结果会有一点偏差。
:::

## 0.3. 分数和除法（Fracciones y divisiones）

分数就是除法。3/4 的意思是 3 ÷ 4 = 0,75。

统计里几乎所有东西都是“某个数除以总数”。比如，44 个人中有 21 个没有兄弟姐妹，比例就是 21/44 = 0,477。

## 0.4. 百分比（Porcentajes）

百分比就是比例乘以 100。

- 比例 0,477 → 百分比 **47,7%**。
- 百分比 12% → 比例 **0,12**。

从 % 变成小数，除以 100。从小数变成 %，乘以 100。

**涨一个百分比。** 涨 5% 就是乘以 1,05。涨 20% 就是乘以 1,20。降 10% 就是乘以 0,90。降 2% 就是乘以 0,98。

::: {custom-style="Truco"}
**💡 小技巧。** “涨 3%”（subir un 3 %）=“乘以 1 + 0,03 = 1,03”。“降 3%”（bajar un 3 %）=“乘以 1 − 0,03 = 0,97”。Tema 4 里会用得非常多。
:::

## 0.5. 乘方（“平方”，Potencias）

平方就是一个数乘以它自己：5² = 5 × 5 = 25。

负数的平方是正数：(−3)² = (−3) × (−3) = 9。这对方差很重要。

在 Excel 里，平方用符号 `^` 写：`=5^2` 得 25。在西班牙语键盘上，`^` 在 P 右边的键，要按 Shift；有时按完还要再按一下空格键才会出来。

## 0.6. 平方根（Raíz cuadrada）

平方根是平方的反运算：√25 = 5，因为 5² = 25。

在 Excel 里：`=RAIZ(25)`（英文版：SQRT）得 5。

还有其他的根（立方根、12 次方根……），Tema 4 会用到。根可以写成分数次方：8 的立方根是 8^(1/3) = 2。在 Excel 里：`=8^(1/3)`。

## 0.7. 符号 Σ（求和，sumatorio）

Σ 是希腊字母大写的“sigma”。它的意思只是**“把这些全部加起来”**。

看到 Σ xᵢ，读作：“把所有 x 值加起来”。看到 Σ xᵢ·nᵢ，读作：“每个值乘以它的频数，再把这些结果全部加起来”。

在 Excel 里，Σ 就是函数 `=SUMA( )`（英文版：SUM）。

## 0.8. 下标（Los subíndices）

下面的小字母（下标）只是用来编号的。x₁ 是第一个值，x₂ 是第二个……xᵢ 的意思是“任何一个值，轮到的那个”。它不是运算。

## 0.9. 区间和括号（Los intervalos y sus corchetes）

区间是一段数字。方括号和圆括号表示端点包括还是不包括：

| 写法 | 读法 | 包括 10 吗？ | 包括 20 吗？ |
|:---|:---|:---:|:---:|
| [10, 20] | 从 10 到 20，两头都包括 | 是 | 是 |
| (10, 20] | 大于 10，到 20 为止 | 否 | 是 |
| [10, 20) | 从 10 开始，小于 20 | 是 | 否 |

**方括号 [ ]**（corchete）= 包括这个数。**圆括号 ( )**（paréntesis）= 不包括这个数。

区间的**组距**（amplitud）= 上端 − 下端。(10, 20] 的组距是 20 − 10 = 10。

**组中值**（marca de clase）= 区间的中点 = (下端 + 上端) / 2。(10, 20] 的组中值是 (10 + 20)/2 = 15。

## 0.10. 计算器（La calculadora）

纸笔考试里，计算器做计算，你做表。一个普通的科学计算器就够了。

**最常用的：**

| 用途 | 按键 |
|:---|:---|
| 平方 | x² |
| 平方根 | √ |
| 其他次方（比如 ³ 或 ⁴） | ^（或 xʸ，或 x■） |
| n 次方根（用于平均变化率） | ˣ√（通常要按 SHIFT），或者求 (1/n) 次方 |
| 用上一个结果 | Ans |
| 存一个数 | STO（或 SHIFT + RCL）再加一个字母 |

::: {custom-style="Truco"}
**💡 小技巧：计算到一半时不要四舍五入。** 如果一个结果后面还要用（比如算方差要用均值），不要抄四舍五入后的数：用 Ans 或者存进内存。只把最后结果四舍五入到 2 或 3 位小数。
:::

### 统计模式：用来检查（El modo estadístico）

几乎所有科学计算器都有**统计**模式（根据型号叫 STAT、SD 或 Estadística）。输入数据，它直接给出均值和标准差。**它不能代替表**（考试要写出步骤），但可以用来**检查**你有没有算错。

屏幕上通常会出现：

| 计算器上的符号 | 在指南里是什么 |
|:---|:---|
| n | 数据个数 |
| x̄ | 均值 |
| Σx | 数据之和 |
| Σx² | 平方和 |
| σx（或 σn、xσn） | 标准差 S（除以 n） |
| sx（或 σn−1、xσn−1） | 修正标准差 s（除以 n − 1） |
| a, b, r | 回归直线和相关系数（Tema 3） |

**一般步骤**（以最常见的卡西欧 Casio 为例；其他牌子也差不多）：

1. 进入统计模式，选 **1 个变量**（1-VAR）。
2. 如果你有频数表，在设置里打开**频数**列（FREQ）。这样每个值只输入一次，再输入它的 nᵢ。
3. 在屏幕上的表里输入数据（和频数）。
4. 退出表（AC），在选项菜单里找**单变量计算**：那里有 x̄、σx、sx、n……

::: {custom-style="Ojo"}
**⚠️ 注意。** σx 是讲义里的标准差 **S**（除以 n）。sx 是修正标准差 **s**。如果计算器给出四分位数（Q1、Q3），可能和讲义的方法不一样：考试时用讲义的方法。
:::

每个型号的按键位置都不一样。用**你自己的**计算器做兄弟姐妹的例子：应该得到 x̄ = 0,977 和 σx = 1,252。如果不对，第一次可以请同学帮忙：只是找按键而已。

# Parte 0 bis. Excel desde cero

## 0.11. 工作表的基础（Lo básico de una hoja）

Excel 工作表是一个网格。**列**（columnas）用字母（A、B、C……），**行**（filas）用数字（1、2、3……）。每个格子是一个**单元格**（celda），用列和行来命名：**B3** 是 B 列第 3 行的单元格。

**范围**（rango）是一组连续的单元格。`B2:B45` 的意思是“从 B2 到 B45”。

## 0.12. 写公式（Escribir una fórmula）

1. 点你想放结果的单元格。
2. **一定**先写 **=** 号。
3. 写运算或函数。
4. 按 **回车**（Intro）。

如果不写 `=`，Excel 会把它当成文字，什么都不算。

::: {custom-style="Ojo"}
**⚠️ 注意。西班牙语版 Excel 用分号。** 函数里的各部分用 **;** 分开，不用逗号，因为逗号是小数点。例子：`=CONTAR.SI(B2:B45;0)`。如果写逗号，Excel 会报错。（英文版和中文版 Excel 用逗号 `,` 分隔，用点 `.` 做小数点。考试按西班牙语写。）
:::

## 0.13. 拖动公式（往下复制，Arrastrar una fórmula）

如果你在 C2 写了 `=B2*2`，想在 C3、C4、C5……也这样：

1. 选中 C2。
2. 把鼠标放在单元格右下角：会出现一个小黑十字。
3. 往下拖（或者双击这个十字）。

Excel 会自动改变引用：C3 里是 `=B3*2`，C4 里是 `=B4*2`……

## 0.14. 用 $ 固定单元格（绝对引用，referencia absoluta）

有时候你希望拖动时某个单元格**不变**。比如，把每个频数除以总数，总数一直在 B9：`=B2/$B$9`。

符号 **$** 把单元格“冻住”。小技巧：写 B9 后按 **F4** 键，Excel 会自己加上 $。

::: {custom-style="Truco"}
**💡 小技巧。** 实用规则：**总数**和**均值**几乎总是要用 $ 固定，因为每一行都要用。
:::

## 0.15. 你会用到的函数（Las funciones que vas a usar）

现在不用背。用到的时候会出现，最后还有一张完整的小抄。

| 用途 | Excel 函数（西班牙语版） | 英文版 |
|:---|:---|:---|
| 求和 | `=SUMA(rango)` | SUM |
| 数有多少个数据 | `=CONTAR(rango)` | COUNT |
| 数某个值出现几次 | `=CONTAR.SI(rango;valor)` | COUNTIF |
| 均值 | `=PROMEDIO(rango)` | AVERAGE |
| 中位数 | `=MEDIANA(rango)` | MEDIAN |
| 众数 | `=MODA.UNO(rango)` | MODE.SNGL |
| 最大和最小 | `=MAX(rango)` 和 `=MIN(rango)` | MAX、MIN |
| 四分位数 | `=CUARTIL.INC(rango;1)`（或 2、3） | QUARTILE.INC |
| 百分位数 | `=PERCENTIL.INC(rango;0,97)` | PERCENTILE.INC |
| 方差（课上用的） | `=VAR.P(rango)` | VAR.P |
| 修正方差 | `=VAR.S(rango)` | VAR.S |
| 标准差 | `=DESVEST.P(rango)` | STDEV.P |
| 修正标准差 | `=DESVEST.S(rango)` | STDEV.S |

| 几何平均 | `=MEDIA.GEOM(rango)` | GEOMEAN |

## 0.16. 插入图表（Insertar un gráfico）

1. 选中数据（比如取值那一列和频数那一列）。
2. **插入**（Insertar）选项卡 → **图表**（Gráficos）组。
3. 选类型：柱形图（columnas）、饼图（circular）、直方图（histograma）、箱形图（cuadro y bigotes）、散点图（dispersión）、雷达图（radial）。
4. 选中图表后，旁边出现的 **+** 按钮可以加**坐标轴标题**、**数据标签**和**趋势线**（línea de tendencia）。

## 0.17. 数据透视表（按类别计数，Tabla dinámica）

它能自动数出每个值或每种组合出现了几次。老师在 Tema 2 里用过。

1. 点数据里的任意一个单元格（数据要有标题行）。
2. **插入**（Insertar）→ **数据透视表**（Tabla dinámica）→ 确定（放在新工作表）。
3. 右边会出现一个列表，是你各列的名字。
4. 把要数的变量拖到**行**（Filas）。
5. 把同一个变量（或另一个）拖到**值**（Valores）。如果显示的是“求和”（Suma de...），点它 → **值字段设置**（Configuración de campo de valor）→ 选**计数**（Cuenta）。
6. 要做双向表，把第二个变量拖到**列**（Columnas）。

::: {custom-style="Truco"}
**💡 小技巧。** 想看百分比而不是个数：右键点透视表里的一个数字 → **值显示方式**（Mostrar valores como）→ **总计的百分比**（% del total general）（或者行 / 列汇总的百分比，用于 Tema 2 的条件分布）。
:::
