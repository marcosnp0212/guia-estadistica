# Plan de estudio

回答三个问题，指南会告诉你每天做什么。

::: {.plan-app}
:::

## 怎么用（Cómo funciona）

有两种计划，**由你选**：

- **速成**，适合只剩几天的时候。大约 13 小时。每个 Tema 按这个顺序学：视频、速成复习、“我会了吗？”、练习题里的重点题，以及样卷里这个 Tema 的题。最后是样卷的简答题、不用电脑的 Excel 题和选择题模拟考试。然后批改，再加强你做得最差的那个 Tema。
- **完整**，适合时间充裕的时候。就是整份指南：每个 Tema 的全部理论、练习题里的所有题、练习和模拟考试。

如果你不选，指南会根据剩下的天数推荐一个。速成计划**内容一样**，不管你提前五天还是两天开始：只是每天的小时数不同。

每做完一项就勾上。今天的任务不会因为你勾掉而改变；剩下的会分到后面几天。如果哪天没法学，没关系：明天计划会重新分配。

::: {custom-style="Idea"}
**🧠 短时间的学习块。** 每学 25 分钟休息 5 分钟。每两个小时休息久一点，20 或 30 分钟，离开屏幕。
:::

::: {custom-style="Ojo"}
**⚠️ 如果只有两天。** 速成计划大约每天 6 个半小时。时间很长，但能做到。把每天分成三段（上午、下午和晚上），中间休息久一点。不要跳过练习题：它们和考试里的计算最像。
:::

::: {custom-style="Truco"}
**💡 如果哪天读不进去，** 先看那个 Tema 的视频。如果一道题卡住超过 10 分钟，打开答案的下一步，从那里继续。
:::

::: {custom-style="Truco"}
**💡 如果百分比或计算器让你害怕，** 打开“更多选项”，勾选“数学基础复习”：计划会把它加在最前面。
:::

::: {custom-style="Truco"}
**💡 没精神的日子。** 如果哪天觉得没力气，只做一件小事：在纸上重做**一道**你已经做对过的题。每天保持接触比做多少更重要。
:::

::: {custom-style="Truco"}
**💡 以后内容更多时。** 如果加了新的 Tema 或者有另一次期中考试，它们会自动出现在“更多选项”的“考试范围”里：勾上这次考试要考的，再改日期。
:::
