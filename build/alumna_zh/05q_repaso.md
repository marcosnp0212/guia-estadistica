## Tema 1：最重要的内容（lo imprescindible）

### 是什么类型的变量

这是第一件要看的事，选择题里几乎一定会考。

- 答案是一个**词**吗？→ **分类变量（cualitativa）**。如果这些词有顺序（低、中、高），就是**有序型（ordinal）**。如果没有顺序（部门、性别），就是**名义型（nominal）**。
- 答案是一个**数**吗？→ **数量变量（cuantitativa）**。如果是用手指数出来的（子女、课程门数），就是**离散型（discreta）**。如果是量出来的、可以有小数（工资、身高），就是**连续型（continua）**。

**参数和统计量。** 参数（parámetro）描述整个**总体（población）**；统计量（estadístico）描述一个**样本（muestra）**。西班牙语的小技巧：**P**arámetro → **P**oblación；**E**stadístico → mu**E**stra。

### 中心：均值、中位数和众数

- **均值（Media，x̄）。** 全部加起来，再除以个数。如果数据在表格里，每个值出现几次就算几次：x̄ = Σxᵢ·nᵢ / n。
- **中位数（Mediana，Me）。** 把数据排好序后，**正好在中间**的那个数据。
- **众数（Moda，Mo）。** **出现次数最多**的值。

**例子。** 工资：1200、1300、1350、1400 和 9000 €。均值是 2850 €，但是没有人挣这么多：9000 把它往上拉了。中位数 1350 € 才代表“一般情况”。

::: {custom-style="Ojo"}
**⚠️ 典型考题。** 有极端值（异常值，atípicos）的时候，用**中位数**或者**截尾均值（media truncada）**（两头各去掉一部分数据再算的均值）更好。它们是**稳健的（robustas）**：极端值动不了它们。
:::

**区间宽度不同时的众数。** 如果区间宽度不一样，不是选数据最多的区间，而是选**每单位宽度**数据最多的区间：也就是**密度（densidad）**，dᵢ = nᵢ / aᵢ。例子：0–10 有 20 个数据（密度 2），10–40 有 30 个数据（密度 1）。众数区间是 0–10，虽然它的数据更少。同样的道理，在宽度不同的直方图里，每个条形的高度是密度。

### 离散程度：数据分开得有多远

- **方差（Varianza，S²）。** 每个数据离均值的距离的平方，再求平均。手算：S² = Σxᵢ²·nᵢ / n − x̄²。
- **标准差（Desviación típica，S）。** 方差的平方根。单位和数据一样。
- **准方差（Cuasivarianza）。** 一样，只是除以 n − 1。在 Excel 里：`VAR.P` 是方差（除以 n），`VAR.S` 是准方差（除以 n − 1）。

**变异系数（Coeficiente de variación）：CV = S / x̄。** 用来**比较**均值或单位不同的两个组的离散程度。没有单位。**越小，越均匀（homogéneo）。** 例子：A 组均值 50，S = 5（CV = 0,10）；B 组均值 10，S = 2（CV = 0,20）。虽然 B 的 S 更小，但更均匀的是 A。

### 四分位数、箱线图和异常值

- **C₁** 下面有 25% 的数据；**C₃** 下面有 75%。中位数是 C₂。
- **IQR = C₃ − C₁**：中间 50% 的宽度。
- **异常值：** 低于 **C₁ − 1,5·IQR** 或高于 **C₃ + 1,5·IQR** 的数据。

**例子。** C₁ = 20，C₃ = 30，所以 IQR = 10，上界是 30 + 15 = 45。47 就是异常值。

**读箱线图。** 如果中位数更靠近箱子的下边，并且上面的须更长，说明分布的尾巴在右边：**正偏（asimetría positiva）**。

### 形状：偏度和峰度

- **偏度（Asimetría，CA）。** CA > 0：尾巴在**右边**（少数几个值很大；均值在中位数上面）。CA < 0：尾巴在左边。CA = 0：对称。
- **峰度（Curtosis）。** 大于 0：很尖（尖峰，leptocúrtica）。小于 0：很平（平峰，platicúrtica）。

### 分组和数据变换

**几个组的方差：** 总方差 = 组内 + 组间。**组内（dentro）**衡量每个组里面数据的变化；**组间（entre）**衡量各组均值之间相差多少。如果“组间”占总方差的很大一部分，说明这几个组差别很大。

**如果对所有数据做 Y = a·X + b**（比如涨 3% 再加 50 €）：均值变成 ȳ = a·x̄ + b，但方差只受乘法影响：S²ᵧ = a²·S²ₓ。**加上一个数不改变离散程度**：大家移动得一样多。

::: {custom-style="Excel"}
**🖥️ 在 Excel 里。** 表格的均值：`=SUMAPRODUCTO(x;n)/SUMA(n)`。标准化 A2 里的数据（均值在 B1，S 在 B2），要往下复制：`=(A2-$B$1)/$B$2`。数据不加 $，因为每一行都变；均值和 S 加 $，因为一直是同一个格子。
:::

## Tema 2：最重要的内容（lo imprescindible）

现在我们同时看每个人的**两个特征**，放在一张列联表（tabla de doble entrada）里：一个变量在行，另一个在列。

### 读表的三种方式

- **联合频数（Conjunta，nᵢⱼ）。** 一个格子：“8 个人是人力资源部的，**而且**在现场办公”。相对频数是 fᵢⱼ = nᵢⱼ / n。
- **边缘分布（Marginal）。** 表格边上的合计。一行的合计是 nᵢ.，一列的合计是 n.ⱼ。这是**只看一个**变量的分布，忘掉另一个。
- **条件分布（Condicionada）。** 放大看某一组：“生产部（Producción）的人里，有多少在现场办公？”。**只取这一行**，除以**这一行的合计**。

### 它们独立吗？

如果**属于哪个组什么都不改变**，两个变量就是独立的（independientes）。比如，如果每个部门现场办公的比例都一样，知道一个人在哪个部门，对猜他是否现场办公没有任何帮助。

用公式表示：**每个格子**都满足 fᵢⱼ = fᵢ. · f.ⱼ。换句话说：**所有条件分布彼此相等，而且都等于边缘分布**。

**例子（样卷里的题）。** 如果总共 70% 的人是全职（jornada completa），而且性别和工作时间独立，那么 70% 的男性是全职。女性也是 70%。

::: {custom-style="Truco"}
**💡 期望频数。** 如果两个变量独立，一个格子里应该有 nᵢ. · n.ⱼ / n。例子：行合计 40，列合计 50，n = 100 → 40 · 50 / 100 = 20。
:::

### 图形

两个分类变量：簇状或堆积条形图，还有**马赛克图（mosaico）**。在马赛克图里，每一列的**宽度**是边缘频数，每一块的**高度**是条件频数。

## Tema 3：最重要的内容（lo imprescindible）

每个人有两个数量变量，比如工龄（antigüedad）和工资。我们想知道它们是否一起变化，并用一个预测另一个。

### 散点图和协方差

每个人是一个点。如果这团点从左到右往**上**走，关系是**正向的（directa）**：一个变大，另一个也变大。如果往**下**走，就是**反向的（inversa）**。

**协方差（covarianza，S_XY）**用一个数说明这一点：S_XY = Σxᵢyᵢ / n − x̄·ȳ。**只看它的正负号**：正的，正向关系；负的，反向关系。它的大小说明不了什么，因为它取决于单位。

### 回归直线

Ŷ = a + b·X 是**知道 X 时猜 Y** 的规则。

- **b = S_XY / S²ₓ**（斜率，pendiente）：X 每多一个单位，Y 平均增加多少。分母是 **X** 的方差。
- **a = ȳ − b·x̄**：起点，也就是 X = 0 时 Y 的值。

**例子（样卷里的题）。** 工资 = 1390 + 78,5 · 工龄。工龄 10 年：1390 + 78,5 · 10 = **2175 €**。工龄每多一年，工资平均多 78,5 €。

**选择题常考的：**

- 回归直线一定**经过 (x̄, ȳ)**。X 对 Y 的直线也经过这一点，所以**两条直线在这里相交**。
- 如果 S_XY = 0，两个斜率都是 0：Y 对 X 的直线是**水平的**（Ŷ = ȳ），X 对 Y 的直线是**竖直的**（X̂ = x̄）。没有线性关系。
- **不要在数据范围以外预测。** 如果工龄是 1 到 15 年，这条直线不能用来预测 40 年：我们不知道离得那么远时关系是否还是直线。这叫**外推（extrapolar）**。

### r 和 R²：关系强吗？

- **r = S_XY / (Sₓ · Sᵧ)**，在 −1 和 1 之间。接近 1，正向关系很强；接近 −1，反向关系很强；接近 0，关系很弱。**它和 b 的正负号相同。** 没有单位：如果把 X 从欧元换成千欧元，**r 不变**。
- **R² = r²**，在 0 和 1 之间。它是**直线能解释的 Y 的变异所占的百分比**。例子：r = −0,85 → R² = 0,7225 → 直线解释了 **72,25%**。平方以后正负号就没有了。

::: {custom-style="Ojo"}
**⚠️ r = 0 不等于“没有任何关系”。** 它的意思是没有**线性**关系。可能有曲线关系，比如 U 形。
:::

::: {custom-style="Excel"}
**🖥️ 在 Excel 里。** `=PENDIENTE(Y;X)`（英文版：SLOPE）、`=INTERSECCION.EJE(Y;X)`（INTERCEPT）、`=COEF.DE.CORREL(X;Y)`（CORREL）、`=COEFICIENTE.R2(Y;X)`（RSQ）。前两个**先写 Y**。
:::

## Tema 4：最重要的内容（lo imprescindible）

指数（índice）说明某个东西相对于参照年份**变了多少**。参照年份叫基期（año base），等于 100。

### 读指数

指数减去 100，就是变化的百分比。

- 指数 125,4 → 上涨了 **25,4%**。
- 指数 92 → 下降了 **8%**。

指数不是欧元：125,4 不是说某个东西值 125,4 €。

### 百分比要相乘

这是这个 Tema 最重要的思想。上涨 10% 就是乘以 **1,10**；下降 20% 就是乘以 **0,80**。每次上涨都是在已有的基础上算的，所以百分比**永远不能相加**：

- 涨 10%，再涨 20%：1,10 · 1,20 = 1,32 → **+32%**，不是 +30%。
- 涨 10%，再跌 10%：1,10 · 0,90 = 0,99 → **少了 1%**。

所以：

- **几年的平均变化率：** 用**几何平均数（media geométrica）**：把各个系数相乘，开方，再减 1。在 Excel 里：`=MEDIA.GEOM(区域)-1`（英文版：GEOMEAN）。
- **从年变化率换成月变化率：** 每年 6% → (1,06)^(1/12) − 1 = **每月 0,487%**，不是 0,5%。
- **反转：** “反过来”的指数是倒数，1/I（用小数表示）。
- **换基期（Cambio de base）：** 每个指数除以新基期那一年的指数，再乘以 100。例子：150 / 125 · 100 = 120。

### 多种商品的指数

- **拉氏指数（Laspeyres）：** 用**基期**的数量（q₀）。因为一直用旧的篮子，它往往会**夸大**价格的上涨。
- **帕氏指数（Paasche）：** 用**当期**的数量（qₜ）。
- **费希尔指数（Fisher）：** 两者的几何平均数，√(L · P)。

西班牙语小技巧：**L**aspeyres = cantidades de **L**a base（基期的数量）。

### 平减（Deflactar）：实际欧元

要去掉通货膨胀的影响，就**除以** CPI（西班牙叫 IPC）：实际值 = 名义值 / IPC，IPC 用小数表示（如果 IPC 以 100 为基数，就是 名义值 / IPC × 100）。

**例子。** 工资 1800 €，IPC 是 1,20，相当于基期的 1800 / 1,20 = **1500 €**。如果工资涨 5%，物价涨 3%，实际工资涨 1,05 / 1,03 − 1 = **1,94%**，不是 2%。

## 选择题的 15 个陷阱（Las 15 trampas del test）

每一个都是经常出现的错误。它们写成问题的形式，让你**自己问自己**：读问题，大声说出或写在纸上你的答案，然后打开看对不对。

从学习的第二天开始，每天一开始花 10 分钟做这些题。答错的记下来，第二天再做一次。考试那天早上，最后看一遍，就够了。

<details><summary>1\. 区间宽度不同：哪个是众数区间？</summary>

**密度**（nᵢ / aᵢ）最大的那个，不是数据最多的那个。

</details>

<details><summary>2\. VAR.P 和 VAR.S 有什么区别？</summary>

**VAR.P** 除以 n：是方差（varianza）。**VAR.S** 除以 n − 1：是准方差（cuasivarianza）。

</details>

<details><summary>3\. 算斜率时题目给的是 S，不是 S²。怎么办？</summary>

先平方。斜率用的是**方差**：b = S_XY / S²ₓ。

</details>

<details><summary>4\. 两个组的均值或单位不同：怎么比较它们的离散程度？</summary>

用 **CV**（S / x̄），不用 S。CV 最小的那个最均匀。

</details>

<details><summary>5\. 数据与均值的离差加起来等于多少？</summary>

**永远是 0。** 上面多出来的正好抵消下面少的。

</details>

<details><summary>6\. 如果给所有数据都加 50 €，方差怎么变？如果都乘以 a 呢？</summary>

加法**不改变**方差：大家移动得一样多。乘以 a，方差乘以 **a²**。

</details>

<details><summary>7\. 组内方差和组间方差怎么合在一起？</summary>

**相加**：总方差 = 组内 + 组间。

</details>

<details><summary>8\. CA > 0：尾巴在哪一边？</summary>

在**右边**。有少数几个很大的值，均值在中位数上面。

</details>

<details><summary>9\. 一个数据什么时候是异常值？</summary>

低于 **C₁ − 1,5 · IQR** 或者高于 **C₃ + 1,5 · IQR** 的时候。

</details>

<details><summary>10\. 在列联表里，怎么知道两个变量是独立的？</summary>

所有条件分布**彼此相等，而且都等于边缘分布**。

</details>

<details><summary>11\. r = 0：是说完全没有关系吗？换单位时 r 会变吗？</summary>

没有**线性**关系，但可能有曲线关系。换单位时 r **不变**。

</details>

<details><summary>12\. r 和 R² 是什么符号？</summary>

R² = r²，所以**永远不是负的**。r 和斜率 b 的**正负号相同**。

</details>

<details><summary>13\. 直线 Ŷ = a + b · X 里的 b 和 a 怎么算？</summary>

b = S_XY / S²ₓ（分母是 **X** 的方差），a = ȳ − b · x̄。

</details>

<details><summary>14\. 涨 10% 再涨 20%：一共涨了多少？每年 6% 等于每月多少？</summary>

1,10 · 1,20 = 1,32：**+32%**，不是 +30%。百分比要相乘，平均变化率用**几何平均**。每年 6% 是 1,06^(1/12) − 1 = **每月 0,487%**，不是 0,5%。

</details>

<details><summary>15\. 拉氏指数用的是哪一年的数量？怎么平减？</summary>

拉氏指数用**基期**的数量。平减就是**除以** IPC（用小数表示）。

</details>

::: {custom-style="Truco"}
**💡 做选择题，先排除。** 选之前把四个选项都读一遍。很多时候有两个选项一看就能排除，因为它们说的是**不可能的**事：CV 是负的、R² 大于 1、方差是负的、“离差之和永远是正的”。剩下两个的时候，用一个小数字例子想一想。
:::
