# Lista para el examen

**开始之前**

- 先把整张试卷读一遍，不要算。标出每道题是哪个 Tema 的。
- 从你最有把握的那道开始。
- 检查计算器是在普通计算模式，不是统计模式（如果你用它检查过什么，要退出来）。

**每道题**

1. 先写出题目要什么和**公式**，再代入数字。即使算错了，公式写对也能得分。
2. 做**表**：xᵢ、nᵢ、Nᵢ、xᵢ·nᵢ、xᵢ²·nᵢ（Tema 1 和 2）或 xᵢ、yᵢ、xᵢ²、yᵢ²、xᵢyᵢ（Tema 3）。每一列都加起来。
3. 每个中间结果写 3 到 4 位小数。**只在最后四舍五入。**
4. 把结果框起来，写上**解释的那句话**（用西班牙语）。

**快速检查**

- Σnᵢ = n 吗？最后一个 Nᵢ 是 n 吗？fᵢ 加起来是 1 吗？
- 均值在最小值和最大值之间吗？中位数也是吗？
- 方差是正的吗？（如果是负的，是忘了平方，或者太早把均值四舍五入了。）
- r 在 −1 和 1 之间，符号和 b 一样吗？R² 在 0 和 1 之间吗？
- 基期等于 100 吗？百分比是相乘（不是相加）吗？

**纸上的 Excel 题**

- 用准确的西班牙语函数名和 `;` 写函数：`=PROMEDIO(A2:A31)`。
- 如果问为什么要加 `$`：为了拖动公式时引用不变。
- 复习“不用电脑的 Excel 题”里的 30 道题。
