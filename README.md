# Guía de Estadística con Excel, desde cero

Guía de estudio de los Temas 1 a 4 de Estadística (RRLL y RRHH, UVigo): teoría explicada a mano y en Excel, boletines resueltos, prácticas que se corrigen solas, simulacros, examen modelo con solucionario, repaso exprés y vídeos.

**Abrir la guía:** https://marcosnp0212.github.io/guia-estadistica/
