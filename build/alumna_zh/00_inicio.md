# Cómo usar esta guía

## 这份指南是怎么做的（Cómo está hecha esta guía）

这份指南是从零开始的。你不需要记得高中学过的东西。我们要用的一切都在这里一步一步讲清楚。

**中文版说明。** 考试是用西班牙语的。所以这里的解释用中文，重要的词后面用括号写上西班牙语，比如 均值（media）。Excel 函数保留西班牙语的名字（考试时就是这样写），第一次出现时也给出英文版的名字。练习题和样卷的题目还附有西班牙语原文。

这门课的统计学不是“很难的数学”。主要是**整理数据、数数、加、除，并且知道每个数字是什么意思**。你会学两种做法：**手算，用纸和计算器**，以及**用 Excel**。两种做法里，你的任务都一样：知道**该做哪个计算**，以及**结果是什么意思**。

每个小节都按同样的顺序，让你知道自己在哪里：

1. **是什么**，用一两句话说。
2. **有什么用**。
3. **怎么手算**，像菜谱一样，放在蓝色的笔记本方框里。
4. **在 Excel 里怎么做**，放在绿色方框里。
5. **怎么解释**，也就是考试时要写哪句话。

你会看到这些彩色方框：

::: {custom-style="Truco"}
**💡 小技巧。** 一个记住某件事或者做得更快的简单方法。
:::

::: {custom-style="Ojo"}
**⚠️ 注意。** 一个常见的错误。慢慢读：能让你考试时少犯错。
:::

::: {custom-style="Mano"}
**✍️ 手算，用计算器。** 在纸上做的步骤，就像不用电脑的考试一样。
:::

::: {custom-style="Excel"}
**🖥️ 在 Excel 里。** 你要在单元格里写的东西。
:::

::: {custom-style="Resultado"}
**✅ 结果。** 最后的答案和解释它的那句话。
:::

::: {custom-style="Idea"}
**🧠 核心思想。** 这个小节真正需要理解的东西。
:::

## 怎么用这份指南学习（Cómo estudiar con esta guía）

上面有五个标签：

- **首页。** 今天要做的事、四个 Tema 和考试入口。
- **我的计划。** 输入考试日期，指南会把学习任务一天一天地分配好。
- **Tema。** 每个 Tema 有四部分：**学习**（视频和理论）、**例题详解**（练习题里的题目）、**练习**（自动批改的题目）和 **我会了吗？**（一张用来检查的清单）。
- **考试。** 速成复习、老师的样卷详解和带分数的模拟考试。
- **工具。** 公式小抄、题目翻译器、考试清单、数字和 Excel 的复习，还有下载。

每一页上，**小节**下拉菜单可以直接带你去任何一个小节，不用经过中间的。最下面有 **上一节** 和 **下一节** 按钮。

一个 Tema 的每个小节都走同样的路：

1. **读**解释，做例子：先手算，用纸和计算器；然后，如果你愿意，再用 Excel。
2. **检查**你是否懂了：小节最后有两三个小问题，马上就能批改。全部答对，这个小节就标为完成。
3. 点最下面的 **下一节**，继续。

进度只保存在这个浏览器里：每个人有自己的进度。首页有一个按钮，可以从你上次停下的地方继续。

最好分成短时间的学习块：专心 25 分钟比盯着屏幕两小时更有用。每两个学习块之间休息 5 分钟。

::: {custom-style="Truco"}
**💡 如果卡住了。** 按顺序这样做：

1. 慢慢重读这个小节，用纸和计算器把例子再做一遍。
2. 如果这个小节有“看不懂？换一种方式讲”，打开它。
3. 用上面的放大镜（或者按 / 键）搜索你不懂的词。中文和西班牙语都可以搜。
4. 做练习时，**一步一步**看答案：只打开下一步，试着自己继续。
5. 如果还是不会，用“添加笔记”把问题记下来，然后继续下一个小节。很多时候，看了下一个小节就懂了。你的笔记都放在右上角纸张图标里。
:::
