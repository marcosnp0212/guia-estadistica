## 考试用的文件（Tus archivos para el examen）

如果考试可以用电脑、**课上的练习**和**一份答案册**，最好提前知道每个文件里有什么，几秒钟就能找到。

### 课上的练习（Las prácticas de clase）

| 文件 | 里面有什么 | 用来做什么 |
|:---|:---|:---|
| Tema1_semana_1 | *Hermanos*（兄弟姐妹）：频数表、均值、中位数、众数、分位数。*Longitudes*（长度）：用 FRECUENCIA 按区间计数、密度。*EncuestaPresupuestosFamiliares*（家庭预算调查）：花费的百分比。 | 频数表、位置指标、区间 |

### 你的答案册（Tu solucionario）

::: {custom-style="Ojo"}
**⚠️ 如果考试是纸笔的。** 如果最后不能带电脑和资料，答案册和课堂练习考试时用不上。但学习时仍然有用：可以在 Excel 里检查你手算的结果。
:::

你的答案册是 **Solucionario_estadistica** 文件，在下一节下载。它是一个 Excel 文件，有三部分：

- **题目翻译器**（traductor de enunciados），有链接通往每类题的计算器和例题。
- **12 个计算器**：粘贴数据就出结果（均值、四分位数、方差、区间的众数和中位数、分组、双向表、回归、指数、拉氏指数、平减……）。
- 讲义和练习题里的**全部例题**，公式都看得见。

考试时：在翻译器里找到那句话，跳到那张工作表，**复制一份工作表**（右键点标签 → 移动或复制（Mover o copiar）→ 建立副本（Crear una copia）），把数据换成考试的数据。这几周也用它来检查你的结果：这样考试那天你就知道怎么用了。

::: {custom-style="Truco"}
**💡 考试之前。** 建一个文件夹 «Examen estadística»，放进课堂练习和答案册。给每个文件起一个你看得懂的名字，比如 «T1 dispersión» 或 «T3 regresión»。考试一开始就全部打开。
:::


## 用 Excel 考试的检查清单（Lista de comprobación del examen con Excel）

**开始之前**

- 开始前打开课堂练习和答案册。把翻译器放在手边。
- 先把整张试卷读一遍，不要算。标出每道题是哪个 Tema 的。如果不确定题目要什么，看题目翻译器。
- 从你最有把握的那道开始。早点拿分能减少紧张。

**每道题**

1. 在一个单元格里写上题目和小题的**标题**（这样你不会迷路，批改的人也能找到）。
2. 把数据复制或写成**带标题的列**。
3. 每一步一列（组中值、xᵢ·nᵢ、xᵢ²·nᵢ、Nᵢ……）。看得见步骤会让你安心，如果有错也容易找到。
4. 每个结果旁边写一个**标签**（"Media ="、"Varianza ="）。
5. 在一个文本单元格里写**解释的那句话**（用西班牙语）。很多时候它和数字一样重要。

**交卷前快速检查**

- 相对频数加起来是 1 吗？最后一个累积频数是 n 吗？
- 均值在最小值和最大值之间吗？
- 方差是正的吗？（如果是负的，一定有错：可能忘了平方，或者减法顺序反了。）
- r 在 −1 和 1 之间吗？R² 在 0 和 1 之间吗？r 和斜率符号一样吗？
- 基期等于 100 吗？
- 除非要求修正方差，你用的是 **VAR.P**（不是 VAR.S）吗？
- PENDIENTE 和 INTERSECCION.EJE 里**先写 Y** 了吗？
- 经常保存文件（西班牙语版 **Ctrl + G**；英文和中文版是 Ctrl + S）。

**有用的快捷键**

| 快捷键 | 用途 |
|:---|:---|
| Ctrl + Z | 撤销 |
| Ctrl + G | 保存（西班牙语版；英文和中文版是 Ctrl + S） |
| F4 | 写引用时加上 $ |
| F2 | 编辑单元格（看公式） |
| 公式（Fórmulas）选项卡 → 显示公式（Mostrar fórmulas） | 看工作表里所有的公式而不是结果（再按一次恢复） |
| 双击单元格的右下角 | 把公式拖到数据的最后 |

**Excel 可能显示的错误和它们的意思**

| 错误 | 发生了什么 |
|:---|:---|
| `#¡DIV/0!` | 你在除以一个空单元格或 0。通常是忘了加 $。 |
| `#¿NOMBRE?` | 函数名写错了（比如：PROMEDIO 不带重音符号是对的；MEDIA 这个函数不存在）。 |
| `#¡VALOR!` | 应该是数字的地方有文字（比如，用点而不是逗号写的数字）。 |
| `#N/A` | 少了一个数据，或者某个范围的大小不对。 |
| `####` | 列太窄了。双击列的边缘把它拉宽。 |
